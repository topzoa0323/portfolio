## 프로젝트 추가 방법
프로젝트 파일을 해당 프로젝트 폴더에 넣고 data/projects.json에 메타데이터를 추가하면 포트폴리오를 확장할 수 있습니다.

현재는 기본 구조만 구성되어 있으며, 실제 이력·경력·자격증·수상경력·프로젝트 내용은 추후 입력합니다.
